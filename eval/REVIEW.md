# Claude 초안 정답 SQL 30개 검토 (2026-11-04)

정답셋 50문항 중 A·B·C 30문항(단순 조회·조인·지표)의 정답 SQL은 Claude 초안이다(`gold_by: claude-draft`).
에이전트도 Claude라서 초안을 그대로 믿으면 같은 실수를 채점이 못 잡는다. 그래서 두 가지로 검토했다.

## 1. 다른 방식으로 다시 계산 — 30/30 일치

[`scripts/crosscheck_drafts.py`](../scripts/crosscheck_drafts.py)는 같은 질문을 **지표 사전 정의에서 바로, 다른 SQL 모양으로** 다시 쓴다.
초안을 고쳐 쓴 게 아니라 일부러 다른 길로 간다:

| 초안 | 교차 검산 |
|---|---|
| 기간: `ord_dtm >= TIMESTAMP '…' AT TIME ZONE 'America/Sao_Paulo'` | `extract(year/quarter/month FROM ord_dtm AT TIME ZONE …)`, `to_char(…, 'YYYY-MM')` |
| `JOIN … USING`, `WITH` | 상관 서브쿼리, `IN`·`EXISTS`, 스칼라 서브쿼리 |
| 리뷰 최신 1건: `DISTINCT ON` | `row_number() OVER (PARTITION BY ord_no …)` |
| 비율: `count(*) FILTER (WHERE …)` | `avg(CASE …)`, `sum(CASE …)` |
| 순매출: 품목 합 − 환불 합 (따로 집계) | 주문마다 (품목 − 환불)을 구해 합산 |

결과: **30문항 모두 정답 SQL과 같은 값**(채점기 `matches`로 비교). 접속 시간대를 UTC와 Asia/Seoul로 바꿔 돌려도 30/30 —
정답 SQL이 접속 시간대에 따라 바뀌지 않는다(함정 T2).

## 2. 질문이 한 가지로만 읽히는지

- **테스트 데이터가 다른 표에 섞이는지**: 테스트 주문은 실제 상품·판매자를 쓰고(테스트 전용 상품·판매자 0개), 테스트 계정의 주문은 전부 테스트 주문(300건)이다.
  그래서 A01·A02·A06·A07(상품·판매자 표만 보는 문항)에 테스트 필터가 없어도 되고, C02·C03에 `is_test_acct` 조건이 있든 없든 값이 같다.
- **순위 문항의 경계**(5위·3위 바로 다음과의 차이):

  | 문항 | 마지막 순위 | 바로 다음 | 판정 |
  |---|---|---|---|
  | A04 결제 수단 | not_defined 3 | — | 동점 없음 |
  | B01 상위 5 카테고리 | computers_accessories 400,490.61 | cool_stuff 388,971.98 | 충분 |
  | B03 판매자 주 3곳 | MG 493,127.48 | RJ 489,675.20 | 충분(0.7%) |
  | B04 지연율 3곳 | BA 10.02% | PE 9.25% | 충분 |
  | B05 리뷰 점수 낮은 3개 | telephony 4.0031 | furniture_decor 4.0092 | **좁음 — 아래** |

- **B05**: 합의된 정의(주문당 최신 리뷰 1건, 주문×카테고리 한 번)로는 telephony가 3위다.
  하지만 리뷰를 품목 행에 조인하면(품목 2개 주문의 리뷰가 두 번 세어지는 팬아웃) 3위가 furniture_decor로 바뀐다.
  팬아웃은 이 정답셋이 잡으려는 함정이라 정답은 그대로 두고, 정답 SQL에 이 차이를 주석으로 남겼다.
  (정식 측정의 B05 실패는 이것이 아니라 '미분류' 해석과 출처 원칙 위반이었다 — [RESULTS.md](RESULTS.md))
- 그 밖에: A01은 "실제로 쓰인 카테고리"(73)와 카테고리 표 행 수(71, 번역 없는 코드 2개)가 다를 수 있어 질문에 "카테고리가 없는 상품은 빼고"를 넣어 두었다.
  A08은 할부 0개월인 신용카드 결제 2건을 그대로 평균에 넣는다(데이터 값 그대로, 결과 3.51은 넣든 빼든 같음).

## 이 검토의 한계

검토도 Claude가 했다. 다른 SQL 모양으로 독립 계산했지만 **같은 지표 사전을 같은 방식으로 읽는 실수**는 이 방법으로 못 잡는다.
그래서 `gold_by: claude-draft`는 그대로 두고 `reviewed: crosscheck`만 붙였다. 사람(호열)의 검토가 끝나면 표시를 바꾼다.
함정·권한 17문항은 사람이 따로 썼으므로, 채점 독립성의 핵심은 그쪽에서 지킨다.
