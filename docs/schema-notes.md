숫자는 2026-10-30 전체 적재 결과 (`python -m inhouse.data.load`, 41초).

## 권한 (2단계, ADR 0002)

| 직원 (DB 역할) | 행 | 고객 개인정보 |
|---|---|---|
| 본사 분석가 `u_e001` | 전체 | 못 봄 |
| 권역 매니저 `u_e101`~`u_e105` (N·NE·CO·SE·S) | 자기 권역 고객과 그 주문·품목·결제·리뷰·환불, 구 요약표 | 못 봄 |
| CS `u_e201`, `u_e202` | 전체 | `v_cust_contact` 마스킹 값만 |

- 상품·판매자·카테고리·좌표·코드 표는 모두에게 보인다. `emp`, `db_user`는 안 보인다.
- 함정 13: **`SELECT * FROM cust`는 권한 오류**다 (개인정보 열 권한 없음). 열을 골라 써야 한다.
- 함정 14: 권역 매니저의 "전체 매출"은 자기 권역 합계다. 에이전트는 "보이는 범위 기준"이라고 밝혀야 한다.

## 결정 메모

- 함정은 고치지 않는다. 고객 DB는 원래 이렇다. 대신 지표 사전(4단계)과 탐색 도구 설명이 이 노트의 내용을 담는다.
- 표·열 COMMENT는 실제 사내 DB 수준으로 짧게 둔다 (함정 설명을 DB 주석에 다 써 두면 현실적이지 않다).
