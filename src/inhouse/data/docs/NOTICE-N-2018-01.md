# 북부 권역 우기 배송 지연 보상 기준

본사 승인 번호: **APR-2018-004**

## 1. 내용
우기에는 하천 운송 일정이 자주 바뀌어 예상 배송일을 맞추기 어렵다. 그래서 아래 기간에는 배송 지연 보상(LATE)의 지연 일수에서 **5일을 빼고** 계산한다.
예: 예상 배송일보다 8일 늦게 도착 → 지연 3일로 보고 보상한다. 5일 이하로 늦은 주문은 지연 보상 대상이 아니다.

## 2. 대상
- 기간: 주문일(현지) 2018-01-15 ~ 2018-04-30
- 대상: 고객 주소가 북부 권역(AC, AM, AP, PA, RO, RR, TO)인 주문
- 파손·오배송 환불은 바뀌지 않는다.
