# 지표 정의 회의록 (2017-12-15)

참석: 데이터팀장, 본사 분석가(Larissa Lima), 권역 매니저 5명

## 1. 안건: "매출"을 하나로
권역마다 매출을 다르게 뽑아 월간 회의에서 숫자가 맞지 않았다.

## 2. 결정
- 회사 공식 매출은 **순매출**: 유효 주문의 품목 판매가 합계 − 그 주문들에 대한 환불. 배송비는 넣지 않는다.
- 환불은 환불한 달이 아니라 **원래 주문의 주문일 기간**에 넣는다.
- 취소 주문은 유효 주문에서 이미 빠지므로, 취소에 따른 전액 환불(CNCL)은 또 빼지 않는다.
- 고객 수는 고객 고유번호(cust_uid)로 센다. 주문마다 새로 생기는 고객번호(cust_no)로 세면 안 된다.

## 3. 참고 숫자 (회의 당시)
2017년 1~11월 순매출 약 520만 헤알 (당시 추정, 12월 미포함). 공식 숫자는 데이터 시스템에서 다시 뽑는다.

## 4. 후속
본사 분석가가 지표 사전을 만들고 데이터팀장이 승인한다.
