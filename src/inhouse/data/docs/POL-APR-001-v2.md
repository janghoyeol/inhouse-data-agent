# 환불 승인 한도 (제2판)

## 1. 적용 기준일
승인 한도는 **승인하는 날** 기준으로 적용한다 (주문일이 아니다). 2018-07-01 이후 승인부터 이 판을 적용한다.

## 2. 한도표 (환불 1건 금액 기준)
| 승인권자 | 한도 | 범위 |
|---|---|---|
| CS 팀장 | R$ 500 이하 | 전 권역 |
| 권역 매니저 | R$ 2,000 이하 | 자기 권역 고객의 주문 |
| 본사 운영책임자 | 제한 없음 | 전 권역 |

## 3. 공통 원칙
- 환불을 제안한 사람은 그 환불을 승인할 수 없다.
- CS 담당은 제안만 할 수 있고 승인권이 없다.
- 제안 후 **72시간** 안에 승인되지 않은 제안은 만료된다. 만료된 제안은 다시 제안해야 한다.
- 한도를 넘는 제안은 한도가 맞는 승인권자에게 넘긴다. 금액을 나눠 여러 건으로 제안해 한도를 피하면 안 된다.
