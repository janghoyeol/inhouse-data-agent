# 환불 사유 코드 안내

환불 기록(`rfnd.rsn_cd`)의 사유 코드 뜻과 누가 넣는지를 정한 정본이다. 데이터에는 코드만 있다.

## 1. 코드
| 코드 | 뜻 | 누가 넣나 |
|---|---|---|
| DMG | 파손·불량 (상품이 깨지거나 작동하지 않음) | CS 담당 제안 → 승인 후 |
| WRONG | 오배송 (주문과 다른 상품이 옴) | CS 담당 제안 → 승인 후 |
| LATE | 배송 지연 보상 | CS 담당 제안 → 승인 후 |
| CNCL | 주문 취소에 따른 결제 전액 환불 | 주문 시스템 자동 (사람이 넣지 않음) |

## 2. 주의
- CNCL은 취소된 주문의 전액 환불이다. 매출을 셀 때 취소 주문을 이미 뺐다면 CNCL 환불을 또 빼면 이중 차감이다.
- 고객이 "반품"이라고 해도 사유가 파손이면 DMG, 다른 상품이면 WRONG으로 넣는다. "반품"이라는 코드는 없다.
