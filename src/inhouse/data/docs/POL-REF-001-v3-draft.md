# 환불·반품 규정 (제3판 초안 — 검토 중, 시행 전)

> 이 문서는 검토 중인 초안이다. 확정·공지 전까지 효력이 없으며 고객 응대나 환불 계산에 쓰지 않는다.

## 1. 주요 변경 (안)
- 신청 기한: 배송 완료 다음 날부터 **30일 이내** (현행 15일)
- 배송 지연 7일 이상: 배송비 전액 + 품목 판매가 합계의 **30%** (현행 20%)
- 오배송(WRONG): 회수 택배비를 회사가 부담 (현행 규정에 언급 없음)

## 2. 검토 일정 (안)
- 2018-10 CS운영팀·권역 매니저 의견 수렴
- 2018-10 말 확정 공지, 2018-11-01 이후 주문부터 적용 예정
