# 환불 처리 절차

## 1. 흐름
1. **접수**: 고객 문의에서 주문번호와 사유를 확인한다.
2. **확인**: 주문 상태(배송 완료인지), 배송 완료일과 신청 기한, 이미 환불된 금액을 데이터에서 확인한다.
3. **금액 계산**: 주문일에 시행 중인 환불·반품 규정(POL-REF-001)으로 금액을 계산한다. 승인된 권역 공지가 있으면 반영한다.
4. **제안**: CS 담당이 주문번호·사유 코드·금액·근거(규정 판·조항)를 적어 환불을 제안한다.
5. **승인**: 승인 한도(POL-APR-001)에 맞는 승인권자가 승인하거나 거절한다.
6. **실행**: 승인된 제안만 시스템이 환불 기록을 만든다. 같은 제안은 한 번만 실행된다.

## 2. 하지 않는 것
- 승인 전에 고객에게 환불을 확정했다고 안내하지 않는다 ("검토 중"으로 안내).
- 환불 기록을 직접 입력하지 않는다. 모든 환불은 제안 → 승인을 거친다.
- 한도를 피하려고 한 건을 여러 건으로 나눠 제안하지 않는다.
