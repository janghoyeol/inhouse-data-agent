# 환불·반품 규정 (제2판)

## 1. 목적
이 규정은 배송이 끝난 주문의 환불·반품 기준을 정한다. 배송 전 주문의 취소는 주문 시스템이 자동으로 처리하며(사유 코드 CNCL) 이 규정의 대상이 아니다.

## 2. 적용 기준일
이 규정은 **주문일(브라질 현지 날짜)** 기준으로 적용한다. 2018-01-01 이후 주문된 건에 적용하고, 그 전 주문에는 제1판을 적용한다.
신청일이 2018년이라도 주문일이 2017년이면 제1판을 따른다.

## 3. 신청 기한
고객은 배송 완료일(현지 날짜) 다음 날부터 **15일 이내**에 환불을 신청해야 한다. 제1판의 7일에서 늘렸다.

## 4. 대상 주문
주문 상태가 배송 완료(60)인 주문만 대상이다. 배송 중인 주문에 대한 문의는 배송 완료 후 다시 접수한다.

## 5. 사유별 환불 금액
| 사유 | 코드 | 환불 금액 |
|---|---|---|
| 파손·불량 | DMG | 해당 품목 판매가 전액 + 해당 품목 배송비 |
| 오배송(다른 상품) | WRONG | 해당 품목 판매가 전액 + 해당 품목 배송비 |
| 배송 지연 1~6일 | LATE | 해당 주문의 배송비 전액 |
| 배송 지연 7일 이상 | LATE | 해당 주문의 배송비 전액 + 품목 판매가 합계의 20% |

- 지연 일수 = 실제 도착일(현지 날짜) − 예상 배송일. 0일 이하는 지연이 아니다 (배송 기준 POL-DLV-001).
- 파손(DMG) 환불이 R$ 100을 넘으면 사진 증빙이 있어야 한다 (GUIDE-CS-004).

## 6. 환불 한도와 제외
- 한 주문의 환불 합계는 그 주문의 품목 판매가 합계와 배송비 합계를 더한 값을 넘을 수 없다. 이미 환불한 금액은 빼고 계산한다.
- 테스트 주문, 취소된 주문, 이미 전액 환불된 주문은 환불 대상이 아니다.
- 같은 주문에 같은 사유로는 한 번만 환불한다.

## 7. 승인
모든 환불은 승인권자의 승인을 받은 뒤 실행한다. 승인 한도는 POL-APR-001, 절차는 GUIDE-CS-002를 따른다.
