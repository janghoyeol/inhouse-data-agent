# 테스트 주문 처리 회의록 (2018-02-08)

참석: 데이터팀장, 본사 분석가, 개발팀 2명

## 1. 문제
주문 시스템 교체(2018-01) 전후로 개발팀이 운영 DB에 테스트 주문을 넣었다. 일부 테스트 품목 가격이 9,999.99라 매출이 크게 부풀었다.

## 2. 결정
- 테스트 주문은 지우지 않고 `is_test` 표시로 구분한다. 모든 지표에서 뺀다.
- 테스트 계정(`is_test_acct`)은 고객 수에서 뺀다.
- 앞으로 테스트는 운영 DB가 아니라 검증 DB에서 한다.
