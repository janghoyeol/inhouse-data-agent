# 북동부 권역 블랙프라이데이 환불 신청 기한 연장

본사 승인 번호: **APR-2017-031**

## 1. 내용
블랙프라이데이 주문이 몰려 배송과 CS 응답이 늦어질 것으로 보여, 이 기간 주문의 환불 신청 기한을 배송 완료 다음 날부터 **14일**로 늘린다 (본사 규정 제1판은 7일).

## 2. 대상
- 기간: 주문일(현지) 2017-11-24 ~ 2017-11-27
- 대상: 고객 주소가 북동부 권역(AL, BA, CE, MA, PB, PE, PI, RN, SE)인 주문
- 환불 금액 기준은 바뀌지 않는다.
