# 판매자 환불 분담 기준

## 1. 분담 원칙
| 사유 | 부담 |
|---|---|
| 파손·불량 (DMG) | 판매자 |
| 오배송 (WRONG) | 판매자 |
| 배송 지연 (LATE) | 회사 (배송사 계약으로 회수) |
| 주문 취소 (CNCL) | 분담 없음 (결제 취소) |

## 2. 정산
판매자 부담분은 다음 달 판매자 정산금에서 뺀다. 한 품목에 판매자가 여러 곳이면 품목의 판매자(`slr_id`)가 부담한다.

## 3. 다툼
판매자가 파손·오배송 판정에 이의를 내면 재무팀이 증빙(GUIDE-CS-004)을 확인해 정한다. 정산 보류는 최대 60일.
