# 권역 매니저 환불 승인 안내

## 1. 승인할 수 있는 건
- 고객 주소가 **자기 권역**인 주문의 환불 제안. 판매자가 어느 권역에 있는지는 상관없다.
- 금액이 승인 한도(POL-APR-001) 안인 제안.

## 2. 승인 전 확인할 것
- 주문일에 시행 중인 환불·반품 규정 판으로 금액이 맞는지
- 신청이 기한 안인지 (배송 완료일 기준, 현지 날짜)
- 이미 환불된 금액을 빼고도 한도 안인지
- 파손 R$ 100 초과·오배송이면 증빙이 있는지 (GUIDE-CS-004)

## 3. 거절할 때
거절 사유를 한 줄로 남긴다. CS 담당이 고객 안내에 쓴다.
