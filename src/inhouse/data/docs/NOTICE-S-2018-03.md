# 남부 권역 배송사 변경 안내

## 1. 안내
2018-03-01 주문부터 남부 권역(PR, RS, SC) 배송을 새 배송사가 맡는다. 송장 번호 형식이 바뀌므로 배송 조회 문의 때 참고 바란다.

## 2. 바뀌지 않는 것
예상 배송일 계산, 배송 지연 기준, 환불 기준은 본사 규정 그대로다.
