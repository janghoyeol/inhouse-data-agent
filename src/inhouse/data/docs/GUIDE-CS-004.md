# 파손·오배송 증빙 기준

## 1. 사진 증빙이 필요한 경우
- 파손(DMG) 환불 금액이 **R$ 100을 넘을 때**
- 오배송(WRONG)은 금액과 관계없이 항상 (받은 상품의 사진)

## 2. 사진 기준
- 상품 전체와 손상 부위가 함께 보일 것, 송장 라벨이 보일 것
- 배송 완료 후 **48시간 안에** 찍은 사진 (사진 정보의 촬영 시각으로 확인)

## 3. 증빙이 없을 때
기준에 맞는 증빙이 없으면 제안하지 않고 고객에게 증빙을 요청한다. 48시간이 지나 증빙을 못 내면 R$ 100까지만 환불을 제안할 수 있다.
