# 남동부 권역 운영 회의록 (2018-06-12)

참석: 남동부 권역 매니저(Vitória Costa), 물류센터장

## 1. 안건: 물류센터 이전 결과
5월 이전 작업 동안 출고가 이틀 멈췄다. 6월 초부터 정상화됐다.

## 2. 지연 보상 두 배 방침
5월 공지(NOTICE-SE-2018-05)의 "지연 보상 두 배"는 본사 승인을 받지 못했다. 본사 CS운영팀은 본사 규정대로 보상하라고 회신했다.
CS팀에 공지 정정을 요청하기로 했다.

## 3. 후속
권역 공지는 본사 승인 번호를 받은 뒤 내기로 했다.
