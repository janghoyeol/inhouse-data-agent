# 북동부 권역 운영 회의록 (2018-02-20)

참석: 북동부 권역 매니저(Paula Gomes), 배송사 담당 2명

## 1. 안건: 배송 지연
2017년 북동부 배송 지연율이 다른 권역보다 높았다. 특히 마라냥(MA) 주가 가장 높았다 (회의 자료 기준 약 15%).

## 2. 결정
- MA·PI 내륙 지역은 배송사와 예상 배송일 계산을 다시 협의한다.
- 지연 보상 비용은 배송사 계약으로 회수한다 (판매자 환불 분담 기준 POL-SLR-001).
