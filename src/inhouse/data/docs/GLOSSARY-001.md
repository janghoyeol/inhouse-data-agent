# 사내 용어집

## 주문
- **유효 주문**: 테스트 주문이 아니고, 상태가 취소(90)·주문 불가(91)가 아닌 주문.
- **배송 완료 주문**: 상태가 60인 주문.
- **테스트 주문**: 개발·검증용으로 넣은 주문. `is_test` 표시. 모든 지표에서 뺀다.

## 지역
- **권역**: 북부·북동부·중서부·남동부·남부 5개. 고객 주소의 주(UF)로 정한다 (판매자 주소가 아님).

## 날짜
- **현지 날짜**: 브라질 현지(America/Sao_Paulo) 기준 날짜. 규정의 기한·기간은 모두 현지 날짜로 센다.

## 돈
- **헤알(R$, BRL)**: 모든 금액의 단위.
- **환불**: 고객에게 돈을 돌려주는 것. 반품·취소와 다르다 (FAQ-CS-001).
