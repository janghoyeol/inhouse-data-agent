# 배송 기준

## 1. 예상 배송일
주문 승인 시점에 주문 시스템이 예상 배송일(`est_dlv_dt`)을 정해 고객에게 안내한다. 예상 배송일은 날짜만 있고 시각은 없다.

## 2. 배송 지연의 정의
실제 도착일이 예상 배송일보다 **늦으면** 배송 지연이다.
- 실제 도착일은 고객 도착 시각(`dlv_cust_dtm`)을 **브라질 현지 날짜**로 바꾼 날이다. UTC 날짜로 비교하면 밤에 도착한 주문이 하루 늦게 잡힌다.
- 예상 배송일과 같은 날 도착하면 지연이 아니다.
- 지연 일수 = 실제 도착일 − 예상 배송일 (일 단위).

## 3. 배송 완료
고객 도착 시각이 기록되고 주문 상태가 배송 완료(60)가 되면 배송 완료로 본다. 배송 완료일은 고객 도착 시각의 현지 날짜다.
