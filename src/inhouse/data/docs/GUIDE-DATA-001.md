# 데이터 요청 가이드

## 1. 어디에 물어보나
- 지표 숫자(매출·주문 수·지연율 등): 데이터 에이전트에 먼저 묻는다. 답의 숫자마다 붙은 쿼리 ID로 실행한 SQL을 확인할 수 있다.
- 지표의 뜻: 지표 사전. 사전에 없는 지표는 데이터팀에 정의를 요청한다.
- 규정·절차: 사내 문서. 숫자는 문서가 아니라 데이터 시스템이 정본이다.

## 2. 볼 수 있는 범위
권역 매니저는 자기 권역 고객의 데이터만 본다. 다른 권역이나 전국 숫자가 필요하면 본사 분석가에게 요청한다.
