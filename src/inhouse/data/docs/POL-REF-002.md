# 결제 수단별 환불 방법

## 1. 원칙
환불 금액은 환불·반품 규정(POL-REF-001)으로 정하고, 이 문서는 **돈을 어떤 방법으로 돌려주는지**만 정한다.
한 주문을 여러 수단으로 나눠 결제했으면, 환불은 **바우처가 아닌 결제분부터** 먼저 돌려주고 남는 금액을 바우처로 돌려준다.

## 2. 수단별 방법
| 결제 수단 | 코드 | 환불 방법 | 처리 기간 |
|---|---|---|---|
| 신용카드 | credit_card | 카드 승인 취소. 할부는 남은 할부를 카드사가 취소 | 카드사 기준 1~2 청구 주기 |
| 체크카드 | debit_card | 카드 승인 취소 | 영업일 5일 이내 |
| 무통장 입금표 | boleto | 고객 은행 계좌로 송금 (계좌 확인 필요) | 영업일 10일 이내 |
| 바우처 | voucher | 같은 금액의 새 바우처 발급 (현금 환불 불가) | 즉시 |
| 미지정 | not_defined | 재무팀 수기 확인 후 결정 | — |

## 3. 할부 결제
할부 개월 수는 환불 금액 계산에 영향을 주지 않는다. 고객에게는 "남은 할부가 취소되고, 이미 낸 할부금은 카드사를 통해 돌려받는다"고 안내한다.
