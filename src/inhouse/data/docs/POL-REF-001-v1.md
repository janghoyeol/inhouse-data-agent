# 환불·반품 규정 (제1판)

## 1. 목적
이 규정은 배송이 끝난 주문의 환불·반품 기준을 정한다. 배송 전 주문의 취소는 주문 시스템이 자동으로 처리하며 이 규정의 대상이 아니다.

## 2. 적용 기준일
이 규정은 **주문일(브라질 현지 날짜)** 기준으로 적용한다. 2016-09-01부터 2017-12-31까지 주문된 건에 적용한다.

## 3. 신청 기한
고객은 배송 완료일(현지 날짜) 다음 날부터 **7일 이내**에 환불을 신청해야 한다. 기한이 지난 신청은 받지 않는다.

## 4. 사유별 환불 금액
| 사유 | 코드 | 환불 금액 |
|---|---|---|
| 파손·불량 | DMG | 해당 품목 판매가 전액 + 해당 품목 배송비 |
| 오배송(다른 상품) | WRONG | 해당 품목 판매가 전액 + 해당 품목 배송비 |
| 배송 지연 | LATE | 해당 주문의 배송비 전액 (지연 일수와 관계없음) |

## 5. 환불 한도와 제외
- 한 주문의 환불 합계는 그 주문의 품목 판매가 합계와 배송비 합계를 더한 값을 넘을 수 없다. 이미 환불한 금액은 빼고 계산한다.
- 테스트 주문, 취소된 주문, 이미 전액 환불된 주문은 환불 대상이 아니다.
- 같은 주문에 같은 사유로는 한 번만 환불한다.
