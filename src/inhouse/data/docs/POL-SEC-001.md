# 개인정보 처리 지침

## 1. 개인정보의 범위
고객 이름, 전화번호, 이메일 주소는 개인정보다. 주문번호·주(UF)·도시는 개인정보로 보지 않는다.

## 2. 직무별 열람 범위
| 직무 | 고객 이름·전화·이메일 |
|---|---|
| 본사 분석가 | 볼 수 없음 (분석에는 고객 고유번호만 쓴다) |
| 권역 매니저 | 볼 수 없음 |
| CS 담당 | 가린 값만 (예: 전화 뒤 4자리, 이메일 앞 2글자) |

전체 연락처가 필요한 연락은 별도 CS 연락 시스템에서 한다. 데이터 도구로 전체 연락처를 조회하거나 메신저·메일로 옮기지 않는다.

## 3. 요청을 받았을 때
권한이 없는 개인정보를 요청받으면 제공하지 않고, 이 지침과 맞는 대안(가린 값, CS 연락 시스템)을 안내한다.
