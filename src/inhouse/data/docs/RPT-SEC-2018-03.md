# 보안 사고 보고서 — 계정 공유 (2018-03)

## 1. 개요
권역 사무실 한 곳에서 DB 관리자 계정 하나를 여러 직원이 함께 쓴 사실이 확인됐다. 이 계정으로 다른 권역 고객의 연락처가 조회됐다.

## 2. 조치
- 공유 계정 폐기, 직원별 계정 발급, 권역별 열람 제한 적용
- 조회 기록 90일분 점검: 외부 유출은 확인되지 않음

## 3. 재발 방지
권한은 애플리케이션이 아니라 DB가 직원별로 거르도록 바꾼다. 조회 기록을 남긴다.
