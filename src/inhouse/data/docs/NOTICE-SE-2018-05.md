# 남동부 물류센터 이전에 따른 배송 지연 안내

## 1. 안내
5월 중 상파울루 물류센터를 새 건물로 옮긴다. 5~6월 남동부 고객 주문은 배송이 2~4일 늦어질 수 있다.

## 2. 고객 보상 (권역 방침)
이 기간 배송 지연 고객에게는 지연 보상을 **두 배**로 해 주기로 권역 회의에서 정했다. 상담 시 적극 안내 바란다.

## 3. 문의
남동부 권역 매니저 (Vitória Costa)
